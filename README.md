# Data Science Postgraduate Projects

- Delivered end-to-end business analytics projects using SQL and Python on raw and 
semi-structured datasets. 
- Applied data preparation, transformation, validation, and exploratory data analysis 
techniques to answer business questions. 
- Built analytical datasets using advanced SQL concepts including joins, aggregations, 
subqueries, and window functions. 
- Conducted A/B testing and statistical inference to support data-driven decision making. 
- Performed feature engineering and data preparation for supervised and unsupervised 
machine learning models. 
- Developed a strong foundation in machine learning, data quality, analytics workflows, 
and business intelligence.

Projects:
- E-news Express Project
- EasyVisa Project
- Trade&Ahead
- INN Hotels Project
